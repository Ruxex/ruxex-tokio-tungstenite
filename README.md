# ruxex-tokio-tungstenite

This repository is a Ruxex-maintained downstream fork of [tokio-tungstenite](https://github.com/snapview/tokio-tungstenite).
It exists solely to publish the Ruxex-compatible package to crates.io and support the Ruxex dependency graph.
Changes are intentionally limited to the proxy compatibility work required by Ruxex.

Thanks to the tokio-tungstenite maintainers and contributors, and to OpenAI OSS Forks for the prior work carried here.
